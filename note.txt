# TASK 7 — Fix Multi-Tab Creation and Batch Browser Commands

## Problem

Dopilot currently cannot reliably execute commands such as:

"Open 10 new tabs."

It handles individual tab operations correctly, but fails to execute multiple tab creations within a single instruction.

## Requirements

### 1. Fix Multi-Tab Creation

Support natural-language commands such as:

- "Open 10 new tabs."
- "Create 5 blank tabs."
- "Open YouTube, GitHub, and Wikipedia in separate tabs."
- "Open 3 tabs and navigate each to Google."
- "Create 10 tabs and switch to the last one."

Ensure the requested number of tabs is created accurately.

### 2. Deterministic Execution

- Handle simple batch commands without calling Groq unnecessarily.
- Extend the existing deterministic command parser.
- Support numbers written as digits or words.
- Use the existing validated browser-tool registry.
- Track actual successful operations rather than assuming completion.
- Prevent duplicate tabs caused by retries.
- Preserve the current tab unless the user requests otherwise.

### 3. Agent Loop Improvements

- Support batch operations within one user instruction.
- Do not let the existing 15-action limit incorrectly block a safe batch operation.
- Count each browser action toward a separate configurable batch limit.
- Set a reasonable maximum of 20 new tabs per request.
- Reject excessive or invalid requests with a clear explanation.
- Allow users to cancel batch operations midway.
- Handle individual tab-creation failures without falsely claiming success.

### 4. Performance

- Execute tab creation efficiently without overwhelming the browser.
- Avoid unnecessary Groq API calls.
- Prevent browser freezing during batch operations.
- Display accurate progress, such as "Creating tab 6 of 10."

### 5. Testing

Test:

1. Creating 1, 5, 10, and 20 tabs.
2. Creating tabs using numbers written in words.
3. Opening multiple different URLs.
4. Creating tabs and switching to a requested tab.
5. Cancelling halfway through a batch.
6. Browser permission failures.
7. Duplicate-request prevention.
8. Chrome and Brave compatibility.
9. Correct progress reporting.
10. Existing single-tab functionality.

Run all existing build, typecheck, lint, unit, and extension verification commands.

Fix any regressions.

## Restrictions

- Preserve existing security and permission checks.
- Do not weaken agent safety limits globally.
- Do not introduce paid services.
- Do not redesign the frontend.
- Do not overwrite `note.txt`.
- Do not create separate Markdown reports.
- Do not deploy automatically.
- Do not commit or push without permission.

## Expected Result

Dopilot must successfully execute:

**"Open 10 new tabs."**

It should create exactly 10 tabs, show accurate progress, and report how many were actually created.

Verify the result in real Chrome and Brave, not just mocked tests.

Provide a concise summary of changes, tests, and any limitations.
